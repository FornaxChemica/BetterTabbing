# Acknowledgments

WindowLens started as a fork of BetterTabbing by Sid Premkumar.

It has been significantly extended and reworked by Chakshu Jain, including the native Cmd-Tab preview augmentation model, compositor-style preview surfaces, Liquid Glass UI work, off-Space/minimized preview handling, and the WindowLens product direction.

WindowLens is inspired by:

- BetterTabbing, for the original macOS window-switching foundation.
- DockDoor, for product-level concepts around native Cmd-Tab and Dock preview augmentation.
- macOS Mission Control, Stage Manager, Spotlight, and VisionOS spatial UI patterns.

DockDoor code and assets are not copied or vendored in this project. If GPL-licensed DockDoor code or assets are ever incorporated, WindowLens licensing must be reviewed and changed accordingly.
